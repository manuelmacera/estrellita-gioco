# Stellina / Estrellita

Tap-to-play review activities for third grade (Italian / Spanish): how the Earth formed, which living things appeared first, the geological eras, the dinosaurs and their extinction, and the animals (vertebrates, invertebrates, insects, breathing, birth, food).

Open: https://manuelmacera.github.io/estrellita-gioco/

Animal pictures: [Noto Emoji](https://github.com/googlefonts/noto-emoji) (SIL Open Font License 1.1), on illustrated backgrounds.
